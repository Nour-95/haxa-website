# HAXA SOCIÉTÉ — Immersive Escape Game Website

A fictional outdoor horror-themed escape game company, developed as an academic web development and business concept project.

The project combines front-end development, interactive features, user experience design and creative storytelling.

## Project Overview

HAXA offers three fictional immersive experiences inspired by horror stories and Alsatian legends:

- **The Witch's Path** — A mysterious forest trail filled with puzzles and supernatural encounters.
- **The Ritual** — An immersive adventure involving ancient rites and hidden secrets.
- **Forest of Shadows** — A psychological horror experience set in a haunted forest.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Features

- Multi-page website with themed activity pages
- Interactive image galleries with JavaScript navigation
- Booking form prototype with client-side data collection
- Interactive modal displaying additional experience information
- Custom visual design and navigation
- Organized image and multimedia assets

## Project Structure

- `index.html` — Main website
- `witch-path.html` — The Witch's Path experience
- `ritual.html` — The Ritual experience
- `forest-shadows.html` — Forest of Shadows experience
- `style.css` — Website styling
- `script.js` — Interactive features and form handling
- `Photos/` — Image assets

## Project Scope

This is an academic prototype created to demonstrate web development and the digital presentation of a fictional business concept.

The booking form simulates a reservation submission using JavaScript. It does not connect to a database or process real reservations.
